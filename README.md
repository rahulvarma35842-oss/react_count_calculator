# React Counter and Calculator

This project contains:
- Counter: Increment, Decrement, and Reset using React `useState`.
- Calculator: Addition, Subtraction, Multiplication, and Division using React `useState`.

## Run the project

1. Extract the ZIP file.
2. Open the extracted folder in Visual Studio Code.
3. Open the terminal in that folder.
4. Run:

   ```bash
   npm install
   npm run dev
   ```

5. Open the local URL shown in the terminal (usually http://localhost:5173).

The calculator checks for empty inputs and division by zero.
